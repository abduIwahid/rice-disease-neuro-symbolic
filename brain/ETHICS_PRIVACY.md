# ETHICS & PRIVACY

- **Educational system, not a real advisor.** Whichever direction is chosen,
  outputs are coursework demonstrations. If direction A: diet output is not
  medical advice. If direction B (healthcare): the system must never be
  presented as diagnostic — the demo script and report carry that line
  explicitly, and demo "patients" are fictional dataset rows.
- **Data:** public datasets only; licence + source recorded per dataset
  (DATA_MODEL.md). No real personal data anywhere — demo users are fictional.
  Images used in the demo come from the dataset's test split.
- **KB honesty:** nutrition/clinical facts cite public sources in code
  comments; uncertain values are marked, never silently invented.
- **AI-tool use (brief §7):** AI assistance is permitted as a learning and
  supporting resource; the team must understand, verify and take
  responsibility for everything submitted. Session logs record what was
  built; the viva rule (every member explains everything) is the enforcement.
- **Bias note (for the report's limitations):** DL models inherit dataset
  bias (e.g. Food-101 skews Western dishes; X-ray sets skew by source
  hospital). One honest paragraph in the report — examiners reward it.
